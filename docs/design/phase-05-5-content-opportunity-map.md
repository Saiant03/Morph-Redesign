# Phase 05.5 — Content opportunity map

What Morph already publishes on morphparfum.ro that the concept can use, checked on 2026-09-24 (rendered pages, WordPress REST API for posts and media, WooCommerce Store API, visual inspection of downloaded images in the scratchpad; nothing was committed). Image paths below are relative to `https://morphparfum.ro/wp-content/uploads/`. Sizes are the natural pixel size of the file served.

Nothing here is invented. Everything under "What needs verification" is a question for Morph or the owner before the asset is used, even in the private concept.

General rules:
- Use in the private concept only, as with the packshots so far; download into `public/morph/` with a provenance manifest (URL, size, date, usage status); never hot-link.
- Morph images are never recoloured, cropped through faces, or retouched.
- Images that appear to be stock or generated (see §3) are not brand imagery.
